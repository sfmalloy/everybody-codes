# Everybody Codes 2026 Solutions

I decided to learn Odin this year. Do not expect the cleanest Odin code you've ever seen, I'm new to the language.

## Running

Running requires downloading inputs manually and saving them to the appropriate file. The format is `inputs/dayXX/partY.txt`. So for day 1 part 3, you would have a file `inputs/day01/part3.txt`.

There are command line flags for running a given day and part. To run day 1 part 3, do:
```bash
odin run . -- -d:1 -p:3
```
